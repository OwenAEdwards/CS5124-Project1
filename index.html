About This Project

This project visualizes data using D3.js, a JavaScript library for creating dynamic and interactive data visualizations. Data Sources: The USDA Atlas of Rural and Small-Town America, TopoJSON's counties-10m.json. Libraries Used: D3.js, TopoJSON.
